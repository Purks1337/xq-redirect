# quality-media.ru — Редирект-хаб на Astro

Официальный сайт-переходник для домена `quality-media.ru` на **Astro**. Разделяет трафик между двумя проектами медиагруппы:
1. **Видеопродакшн** → [ХВАЛИТЕ MEDIA](https://hvalite-media.ru)
2. **Студия подкастов** → [ХВАЛИТЕ QUALITY](https://hvalite-quality.ru)

## Особенности реализации
- **Astro**: Проект полностью собран на Astro в том же стеке и стиле, что и основные сайты.
- **2 горизонтальные карточки с реальными изображениями**:
  - Карточка **ХВАЛИТЕ MEDIA**: темный ретро-стиль продакшна, синий акцент `#3358F4`, шапка ретро-окна с индикаторами, кадр шоурила `media-showreel.jpg`, кнопка перехода и прямые контакты.
  - Карточка **ХВАЛИТЕ QUALITY**: светлый брутальный крафт-стиль подкастов, золотой акцент `#D4A54C`, бейдж `● REC`, реальная фотография лаундж-студии `podcast-studio.jpg`, кнопка перехода и прямые контакты.
- **Усредненный дизайн**: темный графитовый холст с точечной сеткой, шрифты бренда (`Unbounded`, `Golos Text`, `JetBrains Mono`), плотные брутальные тени со смещением.
- **Контакты снизу**: контактный блок с прямыми телефонами направлений, почтой, адресом студии на ул. Ботанической 19, соцсетями (Telegram, WhatsApp, VK, MAX, Instagram) и реквизитами ИП.
- **Без наложений (No overlap)**: выверенная сетка без конфликтующих абсолютных позиционирований; на десктопах помещается в 1 экран, на мобильных аккуратно раскладывается в вертикальный поток со скроллом.

## Команды

```bash
# Локальный запуск в режиме разработки (порт 4321 или 3000)
npm run dev

# Сборка проекта
npm run build

# Предпросмотр собранного проекта
npm run preview

# Запуск собранного standalone сервера
npm start
```
